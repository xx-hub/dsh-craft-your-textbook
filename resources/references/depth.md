# 内容深度（Content Depth）

> 深度机制的核心定义文件。解决"无源造书产出太浅"——没有源材料时，AI 只输出"正确但浅"的常识，缺深层理解。
> 本文是深度四维判定问题的**单一事实源**：style-spec 承诺、写作 agent 自问、审计 agent 核对都引用这里的判定问题，不在此重复展开。
> 与 I3（具体情境素材）区别：I3 要"有具体实体"，深度要"讲到机理/脉络/边界/专家视角"——两者独立，深 ≠ 一定有具体实体，具体 ≠ 一定深。

## 深度四维

| 维度 | 浅（要避免） | 深（要达成） | 判定问题（写作自问 / 审计核对共用） |
|---|---|---|---|
| **机理/原理**（Why） | 只给定义"是什么" | 讲清"为什么"——内部机制、推导、因果链 | 读者读完能解释"这个概念为什么是这样"吗？还是只知道了它是什么？ |
| **脉络/争议**（Where from） | 孤立讲概念 | 从哪来、为解决什么问题而生、历史演变、学派/争议 | 读者知道这个概念为什么存在吗？书里有没有呈现不止一种说法？ |
| **边界/反例**（Where it fails） | 只讲普适正面 | 适用条件、局限、反例、与易混概念的区分 | 读者知道这个概念"什么时候不适用"吗？能和易混概念区分吗？ |
| **专家视角/精度**（Expert's eye） | 百科式无差别描述 | 内行才有的权衡、坑、直觉、量化精度 | 读完像不像内行写的？有没有具体数字/精确区分/取舍判断？ |

## 深度不是灌水

- 深度服务"让 AI 老师/读者抵达更深理解"，不是每段堆术语、掉书袋、引史料
- 本书承诺某维为"浅"时，该维不硬凑——承诺了"中/深"的维度才必须兑现
- 深度与正确性无关：浅但准确的书好过深而杜撰的书——深度 gate 在正确性 gate（L3 引文抽检）之后，不取代它

## 怎么用（承诺制）

1. **Phase 3.3**：本书在 style-spec 声明四维深度目标（默认"中"为底线，声明"浅"须写明理由，经用户确认关卡②认可）
2. **写作时**：写作 agent 对本章核心概念逐个过判定问题（见 `subagent-prompts/writing-agent-prompt.md` 必带第 7 项），自问"我写的这段读者能回答'为什么'吗 / 知道它从哪来、有何争议吗 / 知道边界吗 / 像内行写的吗"
3. **审计时**：审计 agent 按 style-spec 承诺，用本表判定问题逐维核对，判"兑现/未兑现"——审计核对"本书承诺"，非绝对深度（见 `subagent-prompts/audit-agent-prompt.md`；金标准章见 `subagent-prompts/gold-audit-prompt.md`）
4. **回炉**：金标准章承诺维度未兑现 = 回炉（见 `audit-and-testing.md` §七）

## 侧重随书型（Phase 3.1 推导，本文件不预设）

- 认证书（PMP/CPA/法考）→ 重「专家视角/精度」（考点权重、命题陷阱、why-not）
- 入门概念书（科普/哲学/经济学入门）→ 重「机理/脉络」
- 技能书（编程/写作/数学）→ 重「边界/反例」（什么时候用 A 不用 B）
- 语言书 → 重「边界/反例」（易混词/用法区分）
