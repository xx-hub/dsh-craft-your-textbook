# 主角/第二人称戏剧化（Character Protagonist）

## 解决什么教学问题
要不要用一个有名有姓的主角（或第二人称"你"）代入叙事，让读者通过主角的眼睛经历知识的应用过程——主角的疑问、推理、判断成为教学载体。

## 什么时候用 / 什么时候不用
- 用：入门读物/叙事教材/需要读者情感代入的书（CPA 审计、科普、经济学入门）
- 不用：认证类应试蓝本（PMP 明确砍小说层，判断/选择题需要规范叙事不是戏剧代入）；纯参考手册；纯技能书
- 典型搭配：常和 running-case 卡组合（主角在贯穿案例里活动）；常和 scenario-hook 卡组合（章首用主角视角切入）；常和 recurring-leitmotif 卡组合（主角的态度/思维习惯成为低音线的一部分）
- 与 running-case 的关系：两者可独立选择——PMP 用 running-case 不要主角；CPA 两者都用；入门教材可以只用 running-case 不写人物

## 长什么样（结构示例）

CPA Ch1（第三人称主角老周——投资者/报表使用者视角）：
```markdown
老周手里攥着一份打印出来的财务报表，封面上写着"华明制造股份有限公司"。这是一家 A 股上市的精密零部件制造企业，资产总额 12 亿元，营业收入 8 亿元。老周想拿出一笔钱买它的股票，但他翻到利润表那一栏，盯着"利润总额 6,000 万元"这个数字看了很久，心里冒出一个朴素的疑问：这份报表是华明制造的管理层自己编的，他们说赚了 6,000 万就真的赚了 6,000 万吗？
```

CPA Ch1（第二人称代入——注册会计师视角）：
```markdown
换你是那位注册会计师，现在你接下了华明制造的审计。你心里要时刻清楚：你不是华明的人，你也不是替老周炒股的人。你是站在中间、靠证据说话的那一个。你的每一个判断，最终都要经得起一个问题的追问："如果老周问你凭什么这么说，你拿得出证据吗？"
```

结构要点：
- 主角有名有姓（"老周"），不是"某学生"或"你"（第二人称仅作为偶尔的视角切换，不作为默认人称）
- 主角有功能性角色——不是"一个学审计的人"，而是"一个要用报表做投资决定的人"（投资者视角）或"一个要独立检验报表的人"（专业人士视角）。角色功能决定了他会问什么问题、从什么角度理解知识
- 主角的心理活动和判断过程是教学载体——读者通过主角的思考推理学知识，而不是主角在"学知识"
- 主角会犯错、会犹豫、会有直觉偏差——这些恰好是 misconception 卡的素材来源

## 已知陷阱
- 主角有个人情感弧线/成长线/家庭背景/支线故事——变小说偏离教学。主角的价值是"教学视角的载体"，不是"值得同情的人物"。认证类应试蓝本尤其不应使用此卡。
- 第二人称"你是林薇"式小说层，在已对接 Socratopia 等苏格拉底 AI 教学平台的场景下尤其危险——**Socratopia 平台已承担人设/情感线/对话人格的功能，蓝本不重复承担**。蓝本提供的是"教学素材"（情境/问题/判断依据），不是"角色扮演剧本"。如果蓝本写了第二人称主角的完整人设和情感线，会和平台的人设系统冲突，导致 AI 老师在教学时人格混乱。
- 主角太完美/从不犯错——失去通过错误教学的机会。CPA 老周的优势恰恰在于他"不懂审计"——他的朴素疑问就是读者的疑问，他的直觉偏差就是 misconception 的素材。
- 主角视角太窄（只从一个角色的眼睛看世界）——如果书需要多视角（如 PMP 需要从 PM/监理/分包/业主多角度看），单一主角反而限制教学。这种情况考虑不用这张卡。

## 变体
- **第三人称主角**（CPA 老周）：读着像小说，旁观者视角，读者和主角之间保持一定距离，适合"看别人怎么想"的教学
- **第二人称代入**（部分 CPA 段落）：读者直接代入角色，"换你是那位注册会计师……"——适合"你自己来想"的互动时刻，但不宜作为默认人称
- **多角色切换**：从项目经理/监理/分包负责人多角度看同一事件——好处是视角丰富，代价是复杂度高、难以驾驭
- **无主角**（PMP 最终态）：场景中有角色名（老陈/分包负责人）但他们只是"情境中的功能角色"，不展开任何个人视角和心理活动——这是 running-case 不要主角的标准做法

## 不要这样用
- 认证应试蓝本（PMP/法考/医师资格）选这张卡——判断/选择题需要的是规范叙事和可迁移的判断依据，不是戏剧代入。认证类的"情境"是"判断的输入条件"，不是"人物的故事"
- 用主角承载平台已有的情感线/人设——Socratopia 等平台的人设系统由平台管理，蓝本只供教学素材（情境/问题/知识点/判断依据），不重复承担角色扮演功能
- 把主角写成"什么都会的专家"——那读者没法代入，也没法通过主角的错误来教学。主角最好"和读者一样不懂"，通过他的疑问和推理带读者一起学
