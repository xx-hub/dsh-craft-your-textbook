# 多源冲突裁决（Multi-Source Arbitration）

## 解决什么教学问题
多份权威源材料（考纲/PMBOK7/过程组/Scrum 指南等）对同一概念给出不同说法时，怎么表述冲突、怎么裁决优先级、怎么组织双层锚定（判断根层 + 操作层），让 AI 老师和学生都能理解"为什么说法不同"而不是被矛盾卡住。

## 什么时候用 / 什么时候不用
- 用：>=2 份权威源且层级不同/可能冲突（认证类/多教材交叉类最常见）
- 不用：单教材/无源（Mode A）——不存在多源冲突
- 典型搭配：foundation-chapter（判断根来自哪份源）、judgment-card（判断依据回溯到哪份源）、source-material.md（源角色标签）

## 长什么样（结构示例）

### 源角色表（在 META 里声明，每源明确角色和地位）

PMP META 的三源主从关系表：

| 体系 | 角色 | 用法 |
|------|------|------|
| **ECO 35 任务** | 出题主纲 | 考试怎么考，书就怎么组织；每章 frontmatter 挂 eco_tasks |
| **PMBOK7 十二原则 + 八绩效域** | 判断根（PMI-ism 源头） | 讲"为什么这么做"；每章 pmbok7_anchor 锚定 |
| **过程组 + 10知识域 + ITTO** | 操作细节 | 讲"具体怎么做"；每章 process_anchor 锚定 |

### 双层锚定铁律

每个 eco_task 章，先用 PMBOK7 原则/绩效域讲"为什么"（判断根层）→ 再用过程组/ITTO 讲"怎么做"（操作层）。两层各司其职，不能混：

- 判断根层：回答"PMI 为什么倾向于这个做法"——回原则/绩效域
- 操作层：回答"具体步骤、输入输出、工具技术是什么"——回过程组/ITTO

### 三源冲突时的表述范式

当 ECO 任务、PMBOK7 原则、过程组操作三者说法不一致时，不假装无冲突，用固定句式并列陈述：

> "ECO 要求你完成 [X]。过程组的操作是 [Y]。PMBOK7 从原则角度看是 [Z]。"

**裁决优先级**：权威层级最高的源为准，站队后加注解说明差异。具体：
1. 定义/原则冲突 → 以 PMBOK7 原文为准（它是权威原文·真相源）
2. 操作步骤冲突 → 以过程组原文为准（它是操作真相源）
3. 考试覆盖范围 → 以 ECO 考纲为准（它是出题主纲）
4. 敏捷相关内容 → 以 Scrum 指南/敏捷指南为准

PMP META 的素材分工表（见 META.md 第 39-51 行）：

### 防幻觉铁律（多源场景特别强化）

来自 PMP META 第四节（第 55-65 行），多源场景下尤其危险：

1. **打赌测试**：每写一条具名引用/数字/PMBOK 定义/ITTO/"PMI 会怎么选"前，问自己"愿不愿打赌这是真的？"有半点犹豫就回源材料索引核对到具体源文件+行号。
2. **追不到源就降级**：核对不到的，降级为间接转述（"通常认为……"），或干脆不写。绝不杜撰准则定义、过程编号、公式。
3. **最危险的三类，必须逐字回源**：EVM 全套公式、Scrum 3-5-3 各事件时长盒、硬记框架名称（冲突五模式/风险应对策略/塔克曼阶段等）。
4. **偏好断言必标判断根**：写"PMI 首选 X、why-not Y/Z"时，必须标注判断依据来自哪条 PMBOK7 原则或绩效域。标不出依据的偏好断言，宁可不写。

## 已知陷阱
- 假装多源无冲突（"各方说法一致"但其实不一致）→ 加注解说明差异，用固定句式并列陈述
- 一律以某份源为准忽略其他 → 多源各有价值（考纲给靶子、原文给定义、笔记给骨架），不能简单丢弃
- 双层锚定变重复（判断根和操作讲同一件事）→ 判断根讲"为什么"、操作讲"怎么做"，各司其职
- 素材分工表写了但不遵守 → 各章写作时未按分工取料，导致内容来源混乱
- 把 OCR 碎片当骨架起点 → 建源索引时做真相校准，识别"看起来完整其实是碎片"的坑

## 变体
- **双源（师生合版）**：教师用书补充学生用书没有的评价标准/学情分析/常见错误，用 source-material.md 的差异比对方法学处理
- **三源+**（PMP 型）：需要在 META 里明确主从关系表 + 双层锚定铁律 + 冲突表述范式
- **双权威源同级**（如两本并行的官方教材说法不同）：需要在 META 里声明"以哪本为准"并说明理由，不能两本都当真相源

## 不要这样用
- 多源冲突裁决变成"抄各源原文"——要重组为教学主线服务，不是源材料汇编
- 在正文里长篇展开"各源怎么说"——正文以教学主线为准，冲突说明放在 META 和写作指引里，正文里只在必要时用固定句式一笔带过
