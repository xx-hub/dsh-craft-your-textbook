# 贯穿主题低音线（Recurring Leitmotif）

## 解决什么教学问题
怎么设置一条贯穿全书反复出现的主题/态度/推理主轴（非人物、非案例），让知识有"低音"伴奏，不只是散乱的知识点堆砌。学生读完不只是记住了一堆概念，而是被反复浸染出一种核心态度或推理习惯。

## 什么时候用 / 什么时候不用
- 用：需要反复强化某个核心态度/推理范式的书（CPA 的"职业怀疑"、PMP 的"价值交付"、理科的"守恒思维"、编程的"先跑起来再优化"）
- 不用：纯事实/技能书（无反复强化的主题态度）；纯参考手册
- 典型搭配：cross-ref-trace（leitmotif 也是跨章回扣的一种方式，但它是主题重复而非具体指向某章某节）；和 running-case 区别：leitmotif 是主题态度，running-case 是实体公司/项目
- 常和 cross-ref-trace 搭配使用，但两者职责不同

## 长什么样（结构示例）

### 样本 1：PMP 的"价值交付主线"

PMP 示例——价值交付主线：

- **Ch3 首次亮相**：八绩效域中讲"价值交付系统"——点出"价值交付是一条贯穿全书的主线"
- **Ch8 成本预算**：价值的钱——预算是价值的量化表达
- **Ch10 风险**：价值的不确定性——风险是价值偏离的概率
- **Ch17 高潮收束**：价值实现闭环——D3.T2 组织变更/收尾/过渡/价值实现，全书价值线在此收束

### 样本 2：CPA 的"职业怀疑"

CPA 示例——职业怀疑：

```markdown
这里第一次正式登场的，是一个会贯穿全书的态度——**职业怀疑**。正因为证据是说服性的……注册会计师才不能预设管理层一定诚实……这一章只是把它点出来；从第 10 章评价证据开始，它会一次次落到具体的动作上，到第 15 章面对舞弊时达到高潮。
```

- **Ch1 首次点题**：在讲合理保证时点出"职业怀疑是贯穿全书的态度"，明确告知读者"这是一条低音线"
- **第 10 章**：评价证据落地——职业怀疑从抽象态度变成"怎么怀疑一份证据"的具体动作
- **第 15 章**：面对舞弊时达到高潮——舞弊是职业怀疑的终极战场

### 样本 3：CPA 的"风险到程序到证据到结论"审计主干逻辑

- **Ch3 立框架**：审计 = 风险识别 -> 设计程序 -> 获取证据 -> 形成结论
- **后续各章反复用**：每讲一个审计领域（收入/采购/存货/现金），都沿"这个领域的风险是什么 -> 对应什么程序 -> 能拿到什么证据 -> 能得出什么结论"的推理链走

结构要点：
1. **OUTLINE 里声明**：低音线是什么、在哪章首次亮相、在哪章高潮——让写作 agent 从一开始就知道这条线
2. **首次亮相章明确点题**：用"这是一条贯穿全书的主线"类语句告知读者/AI 老师
3. **中间各章自然回扣**：不是每章都提，但关键节点点题——让读者感到"又听到了那个熟悉的低音"
4. **高潮章收束**：把低音线推到最高点，完成闭环

## 已知陷阱
- 低音线太隐蔽，读者/AI 抓不住 → 首次亮相必须明确点题："这是一条贯穿全书的主线"
- 低音线变成口号，每章重复同一句话 → 只在关键节点自然回扣，每次回扣要有新意（新角度/新深度/新情境）
- 和 running-case 混淆 → running-case 是实体（公司/项目/人物），leitmotif 是主题（态度/原则/推理方法）。PMP 的"锦程建工"是 running-case，"价值交付"是 leitmotif。CPA 的"华明制造"是 running-case，"职业怀疑"是 leitmotif
- 和 character-protagonist 混淆 → character-protagonist 是叙事视角（老周），leitmotif 是主题态度（职业怀疑）。老周是"谁的眼睛在看"，职业怀疑是"用什么态度在看"
- 低音线太多（>3 条）→ 读者/AI 记不住，选 1-2 条最核心的即可

## 变体
- **理科**："守恒思维"（物理/化学各章反复出现）、"近似思维"（工程/物理反复强化）
- **编程**："先让它跑起来再优化"的工程态度——每学一个新特性都先给最简版本再优化
- **法律**："比例原则"在各部门法里反复出现
- **医学**："鉴别诊断思维"在内外妇儿各科反复训练

## 不要这样用
- leitmotif 替代跨章引用（cross-ref-trace）——leitmotif 是情感/态度/推理习惯线，cross-ref-trace 是"X 详见第 N 章"的具体知识回扣
- 把 leitmotif 写成 running-case 的情节线——leitmotif 不承载具体人物/事件，只承载主题态度
- 低音线首次亮相不点题，指望读者自己"品出来"——读者/AI 不是文学评论家，教学文本需要明确告知
